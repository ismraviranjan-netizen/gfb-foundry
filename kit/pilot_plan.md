# Pilot plan template — one agent, one site, six weeks

| Week | What happens | Gate |
|---|---|---|
| 0 | Discovery done; profile and mapping filled; data pulled for 12 past weeks | Monitor raises the deviations the planners remember |
| 1 | Agent runs in shadow on last week's data; planners read the diagnoses, mark right/wrong | 70% agreed with the primary cause |
| 2 | Eval set built from the marked cases; thresholds tuned once | Eval pass rate ≥ 85% |
| 3–4 | Live weekly sweep, propose-only; approvals through the real approvers | Time from deviation to decision measured |
| 5 | Cost per run and planner hours saved tallied; failure gallery written | Business case signed by the planning lead |
| 6 | Decision: extend to a second site, add a second agent, or stop | Written decision with the numbers |
