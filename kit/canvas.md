# The one-page agent canvas (fill in 60 minutes; score with the rubric at the end)

| Box | Question it answers | Your answer |
|---|---|---|
| 1 Decision | Which decision does this agent touch, in one sentence? Who makes it today? |  |
| 2 Rung | Inform · Recommend · Propose · Act with approval · Act alone. Which rung, and why not the next one up? |  |
| 3 Trigger | What starts a run: a KPI breach, a schedule, a planner's question? |  |
| 4 Inputs | The tables it reads (name the five), their freshness, their known lies |  |
| 5 Tools | Read tools, write tools, the one tool it must never have |  |
| 6 Logic | What the maths decides and what the model decides; the formula or tree, with one worked number |  |
| 7 Output | The structure a planner reads (fields), and the two-sentence summary |  |
| 8 Approval | Who signs each action; what happens when they do not answer in time |  |
| 9 KPIs | The business KPI it moves; the agent KPI you watch (accuracy, cost per run, latency) |  |
| 10 Evals | The labelled cases: how many clear, ambiguous, traps; the pass bar |  |
| 11 Cost | Cost per run, runs per day, monthly bill; the budget that stops a runaway |  |
| 12 Failure modes | Three ways it fails and the guard for each |  |

## Rubric (0–2 each, 24 max; 18 is a pass, 22 is a canvas you can show a client)
- 0 blank or vague ("uses AI to find issues")
- 1 named but unmeasured ("reads inventory", "planner approves")
- 2 specific and testable (a table name, a threshold with a number, a person with a role, a test that could fail)
